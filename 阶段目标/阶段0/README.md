# 阶段目标

这个文件夹按阶段存放学习目标、任务清单与完成标准。每完成一个阶段，就把对应的勾选框打勾，留下代码和笔记，形成自己的学习进度档案。

## 目录

| 文件 | 阶段 | 内容 |
| --- | --- | --- |
| 阶段0-完成目标.md | 环境搭建 | 需要掌握的内容 + 4 个小任务 + 自测题 |

## 后续阶段文件的统一模板

新建其他阶段的文件时，建议按下面的结构写：

1. **本阶段总目标**：一句话说明学完能做什么；
2. **需要掌握的内容**：按知识点列出"学习目标 + 掌握标准 + 检查清单"；
3. **需要完成的任务**：每个任务写明"做什么 + 验收标准"；
4. **自测题**：能独立回答的问题清单；
5. **完成标准汇总**：全部打勾才算过关。
